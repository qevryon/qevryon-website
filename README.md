# QEVRYON — Hosting Package

Launch domain: https://qevryon.in/

Files:
- index.html — main website
- robots.txt — crawler instructions
- sitemap.xml — basic sitemap for search engines
- assets/ — reserved for future assets

Launch sequence:
1. Create GitHub repository and upload these files.
2. Deploy the repository to Vercel (or another static host).
3. Confirm the temporary hosting URL works.
4. Purchase/register qevryon.in.
5. Add qevryon.in as a custom domain in the host.
6. Add the DNS records requested by the host at the domain registrar.
7. Configure hello@qevryon.in only after domain email service is set up.
8. Verify qevryon.in in Google Search Console and submit sitemap.xml.
